# Passaporte Pré-Lançamento

Crie uma landing page temporária de pré-lançamento para a marca Passaporte para o Caos. Use exatamente as imagens fornecidas como referência e como logo. Não redesenhe a logo, apenas aplique. Não construa o site completo ainda. Quero somente uma página inicial de lançamento, leve, sofisticada e com personalidade. Estética editorial inspirada em viagem, passaporte, histórias, usando fundo claro, azul marinho predominante, vermelho queimado como destaque, tons bege e bastante respiro. No topo, à esquerda, a logo. À direita, apenas Instagram. No centro, uma manchete grande: Viajar também é se perder, com perder em vermelho. Abaixo, texto: Histórias reais de viagens, perrengues, encontros inesperados e tudo o que não estava no roteiro. Em seguida, use uma chamada com personalidade: Já já esse caos decola. Abaixo dela, um botão: Acompanhe no Instagram. Inclua uma composição gráfica sutil baseada na imagem de referência do site futuro, sugerindo elementos de viagem sem poluir. Pode usar uma micro-animação muito leve de rota pontilhada com avião, se não pesar. Mais abaixo, uma pequena frase: Algumas viagens viram lembranças. Outras viram histórias. As melhores talvez sejam justamente aquelas que não saíram como planejado. No rodapé, fundo clean com: © 2026 Passaporte para o Caos. Todos os direitos reservados.
